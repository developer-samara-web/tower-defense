Браузерная игра Tower Defense на Next.js, React и Phaser: волны врагов, прокачка башен, аккаунты, таблица рекордов и сохранение прогресса на сервере.

## Стек

- Next.js 16 (App Router) + React 19 + TypeScript
- Phaser 4 — игровая сцена, карта и бой
- Tailwind CSS 4 — интерфейс
- MongoDB + Mongoose — пользователи, сессии и рекорды
- JWT + bcryptjs — аутентификация

## Требования

- Node.js 22.18 или новее (в репозитории есть `.nvmrc` с 22.23.3: тесты запускаются встроенным Node-раннером с type stripping)
- MongoDB 7+ (локально или в Docker)

## Запуск

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте `.env` по образцу `.env.example`:

   ```env
   MONGODB_URI=mongodb://127.0.0.1:27017/tower-defense
   JWT_SECRET=длинная-случайная-строка
   ```

   В production `JWT_SECRET` обязателен: без него сервер откажется подписывать токены. Для разработки предусмотрен запасной секрет.

3. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

Откройте [http://localhost:3000](http://localhost:3000): стартовая страница ведёт в меню, игру, таблицу рекордов и профиль.

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

`npm test` запускает все файлы `*.test.ts` через `node --test`; специальных зависимостей для тестов не требуется. Те же шаги выполняет GitHub Actions (`.github/workflows/ci.yml`).

## Как играть

- ЛКМ по свободной клетке — построить выбранную башню.
- ЛКМ по построенной башне — открыть панель с характеристиками, улучшением и продажей.
- `1`–`3` — выбрать тип башни (лёд, огонь, земля), `4` или `Esc` — снять выбор.
- `U` — улучшить выбранную башню (до 5 уровня), продажа — кнопкой в панели.
- `Пробел` — запустить волну. После волны предлагается одна из трёх карточек усиления.
- `WASD` / стрелки — камера, ПКМ или СКМ с перетаскиванием — сдвиг карты, колесо — зум.
- На телефоне: свайп двигает камеру, два пальца — зум.
- `R` — рестарт после поражения.

Постройка срабатывает по отпусканию кнопки мыши, поэтому перетаскивание карты не ставит башню случайно. Враги, золото, волна и башни сохраняются на сервере: при следующем входе игра предложит продолжить с того же места. Карта восстанавливается по seed, поэтому дороги остаются прежними.

## Маршруты

| Путь | Назначение |
| --- | --- |
| `/` | Стартовая страница |
| `/auth` | Вход и регистрация |
| `/menu` | Главное меню |
| `/game` | Игра (Phaser) |
| `/leaderboard` | Таблица рекордов |
| `/profile` | Профиль игрока |
| `/api/auth/*` | `register`, `login`, `me` |
| `/api/session` | Сохранение, загрузка и удаление сессии |
| `/api/scores/*` | Обновление рекорда и топ игроков |

## Структура проекта

```
app/                      Next.js App Router: страницы и API-роуты
components/game/          React-оболочка: HUD, оверлеи, миникарта, меню
components/menu/          Экраны меню, профиля и таблицы рекордов
features/account/         Типы профиля и рекордов
features/game/
  config/game.config.ts   Баланс: башни, враги, ресурсы, константы
  domain/                 Чистые правила и состояние игры, формат сессии (+ тесты)
  engine/board/           Отрисовка поля, дороги и ландшафта
  engine/map/             Генерация карты по seed (+ тесты)
  engine/rendering/       Внешний вид врагов и башен
  engine/scenes/          MainScene — сцена-клей
  engine/systems/         Волны, враги, башни
  engine/ui/              Мост в React, управление камерой, уведомления
  types/                  Типы игровых сущностей
hooks/                    useAuth, useGame, useGameUI, useLeaderboard, useProfile
lib/                      JWT, подключение к MongoDB, сервисы API
models/                   Mongoose-схемы User и Session
types/                    Общие типы приложения
```

Phaser и React общаются через браузерные события: `td:state`, `td:select-tower`, `td:start-wave`, `td:upgrade-tower`, `td:deselect-tower`, `td:restart`, `td:game-over`. Состояние публикуется не чаще 10 раз в секунду, а автосейв уходит только при изменении данных.
